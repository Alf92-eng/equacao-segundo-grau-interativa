# Conversor de Medidas

Página interativa do Caderno de Matemática para converter valores entre 13 grandezas, incluindo as unidades métricas mostradas na imagem de referência.

## Como abrir

Abra `index.html` desta pasta em um navegador. Os conversores de medidas funcionam sem instalação e sem servidor. A categoria **Moeda** pode buscar uma cotação de referência na internet; sem conexão, é possível informar a taxa manualmente.

## Recursos

- Conversões para moeda, volume, comprimento, massa, temperatura, energia, área, velocidade, tempo, potência, dados, pressão e ângulo.
- Explicação em etapas, exemplos rápidos, escadas métricas e exercício com pistas.
- Para moeda, a cotação online é buscada no serviço Frankfurter; ela é informativa e pode diferir das taxas cobradas por instituições financeiras.
- Testes manuais pelo navegador em `testes/conversoes.html`.

Para recuperar revisões, use o histórico do Git do repositório e selecione o commit desejado. A página não foi publicada nesta entrega.
