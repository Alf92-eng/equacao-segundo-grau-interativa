01 / ENTENDA

Multiplicação que se repete

Uma potência é uma forma curta de escrever vários fatores iguais multiplicados.

LEIA A EXPRESSÃO

an=a × a × … × a

Para n inteiro positivo, escrevemos n fatores iguais a a. Por exemplo, 23 = 2 × 2 × 2 = 8.

Base a

É o número repetido na multiplicação.

Expoente n

Indica quantas vezes a base aparece como fator.

!

Antes de aplicar as regras

Com expoente 1, a base aparece uma vez: a1 = a.

O expoente zero dá 1 para qualquer base diferente de zero: a0 = 1.

O expoente negativo indica o inverso: a−n = 1/an, se a ≠ 0.

00 não é definido nesta aula, e não podemos dividir por zero.

Um pequeno mapa de regras

02

Divisão mesma base, a ≠ 0

am ÷ an = am−n

Conserve a base e subtraia os expoentes.

03

Potência de potência

(am)n = am·n

Repita os grupos: multiplique os expoentes.

04

Potência do produto

(a · b)n = an · bn

O expoente vai para cada fator.

05

Potência do quociente b ≠ 0

(a ÷ b)n = an ÷ bn

O expoente vai para numerador e denominador.

05 / GUARDE ISSO

Três perguntas para lembrar

Antes de mexer nos expoentes, identifique a operação e confira se alguma divisão envolve zero.

  1. A base é a mesma?Na multiplicação, some expoentes. Na divisão, subtraia.
  2. Há potência fora de parênteses?Potência de potência multiplica expoentes; produto e quociente distribuem o expoente.
  3. O expoente é zero ou negativo?Base não nula elevada a zero vale 1; expoente negativo produz o inverso.
