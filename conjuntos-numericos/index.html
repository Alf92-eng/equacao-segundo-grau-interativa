01 / ENTENDA

Uma família de números

Um conjunto numérico reúne números que compartilham características. Um mesmo número pode pertencer a vários conjuntos ao mesmo tempo.

A IDEIA CENTRAL

ℕ⊂ℤ⊂ℚ⊂ℝ

O símbolo ⊂ significa “está contido em”. Por exemplo, todo número natural também é inteiro, racional e real.

ℕ — naturais

0, 1, 2, 3, … nesta aula.

ℤ — inteiros

…, −2, −1, 0, 1, 2, …

ℚ — racionais

Podem ser escritos como fração de inteiros, com denominador diferente de zero.

𝕀 — irracionais

Não podem ser escritos como fração de inteiros.

ℝ — reais

Reúnem os racionais e os irracionais.

!

Uma convenção importante

Nesta aula, 0 pertence a ℕ: ℕ = {0, 1, 2, 3, …}. Alguns livros usam ℕ* para os naturais positivos {1, 2, 3, …}. Sempre confira a convenção adotada.

O símbolo 𝕀 representa os irracionais nesta página; em alguns materiais, você também pode encontrar ℝ \ ℚ.

ℝ = ℚ ∪ 𝕀   e   ℚ ∩ 𝕀 = ∅

01

Todo inteiro é racional. Basta escrevê-lo sobre 1: −4 = −4/1.

02

Decimal finito ou periódico é racional. Exemplos: 0,125 = 1/8 e 0,333… = 1/3.

03

Raiz de quadrado perfeito pode ser natural. √9 = 3; já √2 é irracional.

05 / GUARDE ISSO

O mapa dos conjuntos

Comece pelo conjunto mais específico que descreve o número.

  1. ℕ está dentro de ℤ.Naturais são inteiros não negativos nesta convenção.
  2. ℤ está dentro de ℚ.Todo inteiro pode ser escrito como uma fração com denominador 1.
  3. ℚ está dentro de ℝ.Frações e decimais finitos ou periódicos são racionais.
  4. 𝕀 fica fora de ℚ, mas dentro de ℝ.Racionais e irracionais, juntos, formam os reais.
