# Matemática Interativa — Equação do 2º Grau

Aplicação educacional gratuita para experimentar coeficientes, acompanhar a resolução de Bhaskara, visualizar a parábola e praticar com exercícios. Feita com HTML, CSS e JavaScript puro, sem instalação nem bibliotecas obrigatórias.

**Acesse o site:** https://alf92-eng.github.io/equacao-segundo-grau-interativa/

## O que você pode fazer

- Digitar `a`, `b` e `c` e ver a equação, o discriminante, as raízes e o passo a passo.
- Escrever uma função diretamente no laboratório gráfico ou mudar a curva pelos três pontos roxos. Pontos alinhados formam uma reta; ao desalinhá-los, a parábola volta.
- Aproximar, afastar e centralizar o gráfico. No computador, a roda do mouse controla o zoom e o botão do meio move o plano.
- No celular, usar os botões `+` e `−` para o zoom. A página faz paradas suaves nas seções e continua rolando normalmente dentro de seções longas. Para manipular o gráfico pelo dedo, escolha um modo de edição e toque em **Ativar toque no gráfico**; depois use **Voltar a rolar a página**.
- Resolver exercícios e receber pistas para cada etapa. A pontuação fica salva neste navegador.

## Executar no computador

Baixe o projeto e abra `index.html` no navegador. Não é necessário servidor, conta ou instalação.

## Versões

- `main`: versão atual, com melhorias de leitura e toque no celular.
- `v2-parabola-interativa`: cópia preservada da versão publicada antes desta revisão.

No GitHub, selecione a versão no menu de branches e clique em **Code → Download ZIP** para baixá-la. O histórico de commits também permite recuperar qualquer revisão anterior.
